## 记忆模式（暂缓，2026-10-27 用户确认先不做，方案保留）

### 位置
「机器人」二级菜单：人设 | 模型 | 语音 | 休息 | 记忆 | 设置

### 表单字段
| 字段 | 默认 | 说明 |
|---|---|---|
| 记忆模式 | 关 | 总开关 |
| 自动记录 | 开 | 每轮对话后 AI 提取 1~3 条值得记的事 |
| 记录范围 | 全部 | 群聊 / 私聊 / 全部 |
| 只记白名单用户 | 关 | 只记白名单 QQ |
| 每人上限 | 20 条 | 超过淘汰最旧 |
| 保留天数 | 永久 | 可设 30/90 天过期 |
| 过滤敏感信息 | 开 | 手机号/密码/证件不记 |
| 聊天带上记忆 | 开 | 回复时注入系统提示 |
| 注入条数 | 最近 10 条 | 控制 token |
| 注入强度 | 中 | 轻/中/强 |

### 管理功能
- 按 QQ 搜索记忆
- 逐条删除 / 清空某人 / 清空全部
- 手动添加记忆（QQ + 内容）

### 待确认

2. 只按 QQ 记，还是也按群记

### 技术方案（草稿）
- 新表 memories(id, qq, content, created_at, source)
- 自动记录：回复后异步调用模型提取，写入表
- 注入：回复前取最近 N 条拼进系统提示
- 管理接口：GET/POST /api/memory/*
