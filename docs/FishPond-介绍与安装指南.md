## 一、这是什么

FishPond（鱼塘）是一个基于 **NapCat + OneBot 协议 + DeepSeek 大模型** 的 QQ 群聊机器人。  
你只需要一台能联网的服务器、一个 QQ 小号和一个 DeepSeek API Key，就能让机器人住进自己的 QQ 号里，在群里聊天、接梗、发表情包。

它不卖课、不收费、不需要注册任何平台账号，所有数据都在你自己的服务器里。

## 二、功能总览

后台是一个网页管理面板（支持手机浏览器访问），功能按一级菜单分为：**状态、机器人、聊天、名单、账号、退出**。

### 1. 状态
- 桥接连接、QQ 登录状态、QQ 号、当前昵称、使用模型、运行时长、收 / 发消息计数
- 最近消息预览
- 实时日志（查看每条消息的处理情况，排错方便）

### 2. 机器人
- **人设（人格切换）**：可以保存多套人格，一键切换"傲娇版 / 舔狗版 / 高冷版"，切换后下一条消息立即生效；也可以直接编辑默认人设的每一句话
- **模型**：内置 DeepSeek，也能接任意 OpenAI 兼容接口（硅基流动、Groq、各种中转都行），支持填 Base URL / 模型名 / Key
- **语音**：
  - TTS 语音回复：支持 Edge-TTS（免费，16 种音色）和豆包 v3（音色下拉选择，如"清车子子"）
  - ASR 语音识别：本地 Whisper（免费，语音转文字，让机器人"听得懂"）或在线 API
  - 可设置首句延迟、消息间隔、表情包延迟，让回复节奏像真人
- **设置**：
  - 版本与更新：一键检查更新，有新版按钮变绿，点一下自动下载、校验、重启，数据全部保留
  - 机器人资料：在线修改 QQ 昵称和头像

### 3. 聊天
- **接话模式**：指定某些 QQ 无论发什么（不用 @、不用关键词）机器人都接话
- **群聊回复**：设置 @ 后持续接话的时长、每分钟回复上限、同时接话人数；支持"一直接话"群；可开启"被 @ 时回复 @ 对方"
- **回复频率**：按群设置每分钟最多回几条、最小间隔秒数；还能设置每次回复拆成 1~10 条（固定或随机），以及每条之间的发送间隔
- **关键词**：说"大肥鱼""小跟班""小弟"等词就触发回复，可增删
- **回复前缀**：给某个 QQ 的回复加上固定前缀（比如"主人，我在呢，"）
- **结束语**：说"没你事了""滚吧"等话，机器人回一句最后的话并结束当前接话
- **表情包**：上传自己的表情包，机器人根据聊天内容智能挑图（AI 选图），也可以设置发送概率
- **无聊模式**：群里长时间没人说话时，机器人按设定间隔出来冒个泡，避免冷群

### 4. 名单
- **白名单**：
  - 群白名单：留空 = 所有群都回；填了 = 只在这些群回复
  - QQ 白名单：留空 = 所有人可用；填了 = 只有这些 QQ 能用
- **超级管理员**：
  - 填写超级管理员 QQ（可多个，逗号分隔），超管消息**优先处理、绕过白名单和频率限制**
  - **舔狗模式**：对超管唯命是从，严格按命令回答
  - **专一模式**：超管发话后一段时间内只回超管，其他人静默，窗口时间可调
  - **怼人模式**：超管在群里 @某人 说"怼他"，AI 结合上下文怼这个人，触发词可自定义
  - **机器人资料**：改昵称、改头像
  - **黑名单**：被拉黑的 QQ 发消息机器人完全不回复；列表显示**头像 + QQ号 + 拉黑时的昵称**，支持后台增删；也可以在群里 @某人 说"加入黑名单 / 移出黑名单"（仅超管）
- **管理员**：管理后台登录账号，可添加多个

### 5. 账号
- **扫码登录**：在后台点"申请二维码"，用手机 QQ 扫码即可让机器人上线，不用手动配置协议

### 6. 其他贴心细节
- @ 别人时机器人不插嘴，避免"别人聊天它乱回"
- 能看懂别人**引用的消息**（引用文字和图片都能读到）
- 支持语音消息互相理解（发语音 → 转文字 → 回复）
- 内置安全红线：拒绝黄赌毒、暴恐、诈骗等违法违规内容
- 一键更新：以后作者发新版，用户在后台点"检查更新"即可升级，不用重装

## 三、安装前需要准备什么

### 必需项

| 项目 | 说明 |
|---|---|
| 一台服务器 | Ubuntu 20.04+ / Debian 11+，1 核 2G 内存起步（有 swap 更稳） |
| 一个 QQ 小号 | 建议新注册的小号，不要用大号，避免风控 |
| DeepSeek API Key | 到 DeepSeek 官网申请，充值少量即可；也支持其他 OpenAI 兼容接口 |

### 可选项

| 项目 | 说明 |
|---|---|
| 域名 | 想让后台有固定网址就准备一个（香港/海外服务器免备案，国内服务器需备案） |
| 语音识别模型 | 约 75MB，安装时会询问，可跳过；跳过则"听懂语音"功能不可用，其他正常 |
| 豆包语音 Key | 想要更好的 TTS 音色可以开通，非必需 |

### 服务器要求
- 能访问外网（GitHub、DeepSeek、PyPI）
- 建议开放 22 端口（SSH）
- 用域名的话需开放 80 / 443
- 香港/海外机器无需域名备案

## 四、安装步骤

### 第一步：拿部署包
联系作者获取加密部署包 `qqbot-deploy.tar.gz.enc` 和解压密码（免费，请勿购买）。

### 第二步：上传到服务器并解密
```bash
# 上传后执行（密码换成作者给的）
openssl enc -d -aes-256-cbc -pbkdf2 -iter 200000 \
  -in qqbot-deploy.tar.gz.enc -out qqbot-deploy.tar.gz \
  -pass pass:你的密码

tar xzf qqbot-deploy.tar.gz
cd qqbot-deploy
```

### 第三步：一键安装
```bash
sudo bash install.sh
```

安装过程中会依次询问：
1. **DeepSeek API Key**（可以直接回车跳过，之后在后台补）
2. **是否安装本地语音识别**（约 75MB，选 n 可跳过）
3. **管理页面访问方式**：
   - `1` 临时外链（Cloudflare 隧道，免费、无需域名，地址重启可能变化）
   - `2` 自己的域名（需已解析到本机、开放 80/443，自动申请 HTTPS）
   - `3` 仅本地访问（用 SSH 隧道访问）

脚本会自动安装 Docker、NapCat、Python 依赖，并启动服务，最后输出：
- 管理后台地址
- 管理员账号 `admin`
- 管理员密码（随机生成，请保存）
- NapCat Token

### 第四步：扫码登录 QQ
1. 打开管理后台，用 `admin` + 密码登录
2. 点「账号」→「扫码登录」→「申请二维码」
3. 用手机 QQ（小号）扫码
4. 看到"在线"即登录成功

### 第五步：基础配置
1. 「名单」→「白名单」添加允许机器人回复的群号
2. 「聊天」→「关键词」按需增删触发词
3. 「机器人」→「人设」改成你想要的人设
4. 「机器人」→「语音」按需开启语音/音色
5. 「名单」→「超级管理员」填自己的 QQ，开启想要的模式

到此就全部完成了，去群里 @ 它试试。

## 五、常见问题

**Q：机器人不回消息？**
检查：①后台状态是否在线 ②群是否在白名单 ③是否 @ 了它或说了关键词 ④回复频率是否被限频（日志会显示"限频丢弃"）。

**Q：会不会封号？**
任何第三方 QQ 机器人都有风控风险，建议：用小号、回复频率别太激进、不要频繁拉群、不要发违规内容。

**Q：能换模型吗？**
可以，「机器人」→「模型」支持任意 OpenAI 兼容接口。

**Q：以后更新麻烦吗？**
不麻烦。后台「设置」→「检查更新」，有新版按钮变绿，点一下自动更新并重启，数据全部保留。

**Q：源码收费吗？**
