Quick Start

三步，让它住进你的 QQ

没有复杂配置，会复制粘贴命令就行。

下载并解密

联系作者获取加密部署包和解压密码。

openssl enc -d -aes-256-cbc \ -pbkdf2 -iter 200000 \ -in qqbot-deploy.tar.gz.enc \ -out qqbot-deploy.tar.gz \ -pass pass:你的密码

一键安装

运行安装脚本，按提示选择访问方式。

tar xzf qqbot-deploy.tar.gz cd qqbot-deploy sudo bash install.sh

扫码上线

登录后台 → 账号 → 扫码登录 → 手机 QQ 扫码。

FAQ

常见问题

机器人不回消息怎么办？

依次检查：后台状态是否在线 → 群是否在白名单 → 是否 @ 了它或说了关键词 → 回复频率是否被限频（日志里会显示「限频丢弃」）。

会不会封号？

第三方 QQ 机器人都有风控风险。建议用小号、控制回复频率、不要频繁拉群、不发违规内容。

需要什么配置的服务器？

Ubuntu 20.04+ / Debian 11+，1 核 2G 起步；想用本地语音识别建议 2G 以上并开 swap。香港或海外服务器免备案。

以后更新麻烦吗？

不麻烦。后台「机器人 → 设置 → 检查更新」，有新版按钮会变绿，点一下自动更新重启，数据全保留。

收费吗？

完全免费开源，谨防有人拿它卖钱。
